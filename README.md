# Bank Account Management System

A simple interactive Bank Account Management System developed using Java to demonstrate Object-Oriented Programming (OOP) concepts.

## Features

- Create and manage two independent bank accounts.
- Deposit money into an account.
- Withdraw money from an account.
- Check the current account balance.
- Display account details.
- Prevent withdrawals when the available balance is insufficient.
- Validate deposit and withdrawal amounts.
- Interactive menu-driven interface using Java Scanner.

## How to Run

**1. Clone the repository**

```bash
git clone https://github.com/pi8tol/BankAccountManagement.git
```

**2. Navigate to the project directory**

```bash
cd BankAccountManagement
```

**3. Compile the Java program**

```bash
javac Main.java
```

**4. Run the program**

```bash
java Main
```

## OOP Concepts Implemented

- **Class:** Defines the BankAccount blueprint.
- **Objects:** Creates two independent bank accounts.
- **Constructor:** Initializes account details.
- **Methods:** Implements deposit, withdrawal, balance checking, and displaying details.
- **Encapsulation (basic object organization):** Groups account data and related operations within a class.
